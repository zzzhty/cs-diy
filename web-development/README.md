# Web 开发

Web 方向覆盖前端与后端接口开发，以做项目为主线。领域划分与课程推荐参考 [csdiy.wiki](https://csdiy.wiki/)（CS自学指南）的 Web开发 章节。

- [`frontend/`](frontend/)：HTML/CSS/JS 基础与现代 React 前端（方向索引）
- [`rest-api/`](rest-api/)：通用图像分类 API 练习，覆盖 HTTP 基础、端点设计与离线测试。

## 推荐课程（来自 csdiy.wiki）

- **Full Stack open**（赫尔辛基大学，[中文版](https://fullstackopen.com/zh/)）：React 单页应用 + Node.js REST API + GraphQL + MongoDB + 测试与部署，难度 2/5，前后端一体，是本方向的主线
- **CS571**（UW–Madison，[cs571.org](https://cs571.org)）：React 与 React Native 工程实践 + UX 设计，12 周，作业量大，难度 3/5，适合在 Full Stack open 之后深入
- **CS142**（Stanford）：Web 应用开发全貌；**MIT web**：Web 开发入门，可作补充

两条线可以穿插：先在 `frontend/` 打好基础，再通过 `rest-api/` 的项目把前后端串起来。轨道启动时按根 README 的专题组织约定补齐 MISSION.md 等工作区文件。
