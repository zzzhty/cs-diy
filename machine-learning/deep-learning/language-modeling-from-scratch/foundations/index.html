两周 LLM 入门基础

你已经有深度学习基础，因此不重复讲反向传播或矩阵乘法；这两周只补齐从深度学习到语言模型所缺的概念、张量视角和推理流程。

第 1–2 周 约 16 小时 进入实现前完成

完成后的能力

你应能从 token 序列写出训练目标，解释 loss/perplexity，追踪一层 causal attention 的 Q/K/V，并准确说明 KV cache 为什么只服务于自回归推理。

第 1 周：语言模型到底在训练什么

核心问题是：如何把文本变成 token，以及如何把一个序列变成“预测下一个 token”的监督样本。

  • 第 1 课：下一个 token 与微型过拟合
  • 核心语言模型速查：token、logit、cross-entropy、perplexity、因果掩码

本周证据：不看资料写出 input/target 的右移关系，并解释“微型过拟合”为什么先于大规模训练。

第 2 周：Transformer 如何读取过去

核心问题是：Q、K、V 各自从哪里来，因果掩码做了什么，以及生成时为何缓存 K/V 而不是重新计算整个前缀。

  • 第 2 课：QKV、因果注意力与 KV cache
  • QKV 与 KV cache 速查

本周证据：画出单层 attention 的张量流，并能区分训练阶段与逐 token 生成阶段的计算。

范围边界

这两周的目标是建立可用于实现的模型，不是背完 Transformer 论文。KV cache 的概念必须掌握，但第一个训练基线可以先不实现 cache；先把无 cache 的生成跑对，再把 cache 当作受控优化。

进入实现阶段

完成基础练习后，按 Mini LLM 练习路线 进入环境、数据 batch 和测试阶段，再打开 Assignment 01 的实现说明。时间安排由练习者自行决定。
