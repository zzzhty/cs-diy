QKV、因果注意力与 KV cache

这一课不要求你实现 attention；目标是能画出一次生成 step 的数据流，并知道 cache 到底缓存了什么。

预计 25 分钟 阶段：补充基础 · 第 2 周 输出：一张正确的推理流程图

这节课和你的 mission 的关系

你的 demo 必须能生成文本。生成不是把整个 prompt 每次重新跑一遍，而是一次产生一个 token。理解 QKV 与 KV cache，会让你在之后看到显存、延迟和生成 bug 时知道该检查哪里。

从 H 到 attention 输出

每层先把隐藏状态 H 投影成 Q、K、V。当前 token 的 Q 与所有可见位置的 K 计算相似度，softmax 后再对 V 做加权求和。因果 mask 保证它看不到未来。

current H  →  current Q, current K, current V
current Q  →  compare with visible K
weights    →  mix visible V
output     →  predict the next token

需要更完整的公式和形状时，打开 QKV 与 KV cache 速查。

检索练习

在自回归生成中，过去 token 的哪一组投影会和 K 一起被缓存？

把 cache 放进正确的位置

先处理完整 prompt，得到每层的 past K/V。之后每产生一个新 token，只计算该 token 的 Q/K/V；将新 K/V 追加到 cache，并让新 Q 查询全部 cache。过去的 Q 不会在下一步复用，所以不需要缓存。

25 分钟行动

  1. 在纸上画三列：past K/V、current Q/K/V、attention output。
  2. 在图中标出：训练时输入整段序列；decode 时输入最新 token。
  3. 写一句自己的规则：为什么第一个训练基线可以不实现 cache。
完成后自查

若你能解释“cache 改变的是推理时的重复计算，不是训练目标”，就已经达到本课目标。若说不清，请回到速查页的 KV cache 小节。
