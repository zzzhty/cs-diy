Mini LLM demo · Lesson 0001

下一个 token 与微型过拟合

先建立 mini LLM 最重要的正确性证据：模型究竟在预测什么，以及如何用最小数据集证明训练链路真的工作。

预计 20 分钟 阶段：补充基础 · 第 1 周 输出：一个清晰的第一个测试目标

这节课和你的 mission 的关系

先在微型语料上建立一个可验证的训练任务：观察失败、检查输入和目标，再确认模型能够过拟合。这样扩展模型或迁移设备时，后续错误更容易定位。计算预算由练习者自行设置。

一个语言模型只做一件事

在位置 t，模型读取此前 token，并给词表中的每个候选 token 打分。训练目标是紧随输入位置的那个 token：

input:   T0   T1   T2
target:  T1   T2   T3

这叫下一个 token 预测。更完整的公式、术语和因果掩码见 核心语言模型速查。

检索练习

不看上面的序列：当输入位置是 T1 时，训练目标是哪一个 token？

为什么第一项证据是微型过拟合

在几十个 token 的固定语料上，模型应能把训练 loss 显著压低。如果做不到，问题几乎总在数据右移、因果掩码、梯度、优化器或训练循环中，而不在“模型还不够大”。先把这个闭环跑通，GPU 时间才值得投入。

20 分钟行动

  1. 在不查资料的情况下，口头复述 input 与 target 为什么只相差一个 token。
  2. 为将来的第一个测试写一句契约：给定固定 token 序列，batch 返回的 target 必须等于 input 左移一位。
  3. 在实验模板中预先写下第一个成功判据：固定微型语料上的训练 loss 持续下降。
完成后自查

你应能解释两件事：为什么目标不能等于 input 本身；为什么修改未来 token 不应改变此前位置的 logits。若其中任何一项说不清，请先回到速查页，而不是开始堆代码。
