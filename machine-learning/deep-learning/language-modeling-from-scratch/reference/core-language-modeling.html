核心语言模型速查

第一阶段只需要牢固掌握这些概念。它们既是实现接口，也是调试时最先检查的契约。

下一个 token 目标

给定 token 序列 x0, x1, …, xT，模型在每个位置根据此前 token 预测下一个 token。训练时输入与目标只相差一个位置：

input:   x0   x1   x2   ...   x(T-1)
target:  x1   x2   x3   ...   xT
L = -(1 / T) · Σ log pθ(xt | x0, …, x(t-1))

交叉熵 loss 越低，模型对真实下一个 token 分配的概率越高；perplexity 是 exp(loss)，用于更直观地比较同一 tokenization 下的语言模型。

因果掩码

位置 t 只能关注位置不大于 t 的 token。实现验证方法：在输入末尾改动未来 token，位置 t 及以前的 logits 不应变化。

QKV 与 KV cache 的张量视角见 QKV 与 KV cache 速查。

正确性优先顺序

  1. tokenizer 能稳定地 encode、decode 和保存。
  2. 数据 batch 的 input/target 右移正确且训练/验证集隔离。
  3. 模型 shape、因果掩码和梯度正常。
  4. 在固定的微型语料上过拟合。
  5. 最后才扩大数据、模型或 GPU batch size。

术语

术语本项目中的含义
token模型处理的离散文本单位；由 tokenizer 映射为整数 ID。
logitsoftmax 之前、对词表中每个 token 的未归一化分数。
causal只使用过去与当前位置的信息，不能查看未来 token。
cross-entropy训练时衡量预测分布与真实下一个 token 的差异。
perplexity交叉熵的指数形式；仅在相同 tokenizer 与数据划分下比较。
