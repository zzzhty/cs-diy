Mini LLM 练习清单

这是可按自己的计算预算与进度调整的通用路线。先理解语言模型基础，再为每一步给出可观察、可复现的结果。

Demo 完成定义

  • 一个可复现的训练命令和配置文件。
  • 一个固定验证集上的 loss 与 perplexity 报告。
  • 一个从固定 prompt 生成文本的演示入口。
  • 一份实验记录，包含 seed、硬件、数据版本、配置和结果。

练习阶段

阶段焦点证据
1LLM 基础：token、下一个 token、loss、perplexity 与生成手工追踪一个 batch，并完成右移目标练习
2Transformer 基础：QKV、因果注意力与 KV cache画出注意力张量流，并解释 cache 的推理角色
3环境、张量、数据 batch 与测试习惯微型 batch 的右移测试与 CPU 运行记录
4子词 tokenizer 与数据切分encode/decode 往返、确定性与数据泄漏测试
5因果注意力与 Transformer blockshape、因果掩码与梯度测试
6优化器、训练循环与 checkpoint微型语料的过拟合曲线
7正式小规模训练与验证首份可复现实验记录
8采样、生成与 demo 入口固定 prompt 的生成样例
9在显存预算内做一项受控改进基线与改进实验的对比
10复现、文档、演示与复盘从零运行的 demo 与项目总结

计算预算规则

先在 CPU 与微型语料上证明逻辑正确，再迁移到 GPU。每次改变 batch size、上下文长度或模型尺寸时，都记录实际峰值显存和吞吐；不要仅凭显卡型号猜测可训练规模。

范围锁定

在形成小型、可复现的基线之前，先不扩展到分布式训练、大规模数据工程或后训练；这些内容可以成为后续独立练习。
