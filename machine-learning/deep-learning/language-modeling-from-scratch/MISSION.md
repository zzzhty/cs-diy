# 练习目标：一个可复现的小型语言模型

参考 Stanford CS336 的公开材料，自行实现 tokenizer、因果 Transformer、优化器、训练
循环与文本生成。使用合成或许可清楚的小型语料，不提交课程答案、个人记录或受限数据。

先用 CPU 与微型数据证明逻辑正确，再由学习者自行设置计算预算。完成标准包括可复现
配置、固定验证集的 loss/perplexity、固定 prompt 的生成入口，以及可独立复核的测试。
数据、硬件和时长由练习者显式选择；本仓库不记录某个人的设备、时间表或学习进度。

分布式训练与后训练可在形成可复现基础后另设练习。资料来源见 RESOURCES.md；公开
教材保持通用，私有实验日志留在仓库外。
