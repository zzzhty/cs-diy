远程访问

从 cs-diy/ 仓库根目录运行：

scripts/serve-web.sh --port 8000

再在任意可达浏览器中打开：

http://<server-ip>:8000/machine-learning/deep-learning/language-modeling-from-scratch/

若从 machine-learning/ 目录运行同名入口，使用保留的旧 URL：

cd machine-learning
scripts/serve-web.sh --port 8000
http://<server-ip>:8000/deep-learning/language-modeling-from-scratch/
主线参考 Stanford CS336。 静态页面由本仓库的远程访问脚本提供服务。
